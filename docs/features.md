# Features

## Carousel

Users can:

- View 5 images simultaneously
- See panoramic depth effect
- Experience automatic glide
- Swipe through images
- Tap images for expanded view
- Enter fullscreen mode

## Uploads

Users can:

- Upload between 5 and 25 images
- See remaining upload capacity
- Replace uploaded images

## Visual Effects

Users can:

- Experience neon animated background
- Experience depth scaling
- Experience smooth transitions
