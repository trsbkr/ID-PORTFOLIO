# Features

## Carousel System
---

Users can:

* View 5 images simultaneously
* Experience 120° panoramic depth
* Experience continuous auto glide
* Swipe left and right
* Use navigation arrows
* Stop at center-card edges
* Experience edge feedback effects

---

## Project Preview

Users can:

* Tap center card
* Open task preview
* View project image
* View project summary
* Return to carousel
* Open full project page

---

## Upload System

Users can:

* Upload between 5 and 25 images
* Replace uploaded images
* Monitor remaining upload capacity
* Receive upload reminder notification

---

## Visual Effects

Users can:

* Experience depth scaling
* Experience smooth transitions
* Experience backdrop blur
* Experience card lift animation
* Experience glow feedback
* Experience recline feedback
* Experience bounce feedback
